# Промпты для ChatGPT Image 2.0

## База — подставляется в начало каждого кадра

```
Создай промо-изображение для карточки мобильного приложения в магазине RuStore.
Размер холста: ровно 1080 × 1920 пикселей, вертикальный.

ПРАВИЛО 1 — СКРИНШОТ НЕПРИКОСНОВЕНЕН.
Приложенный скриншот вставляется в экран телефона без единого изменения. Не перерисовывай
интерфейс, не меняй ни одной буквы, цифры, иконки, отступа или цвета внутри экрана.
Не переводи текст, не «улучшай» вёрстку, не дорисовывай элементы. Это точный контент,
а не референс для рисования. Если вставить изображение как есть невозможно — напиши об этом
текстом, но не перерисовывай интерфейс по-своему.

ПРАВИЛО 2 — ГЛАВНОЕ: ЭКРАН ДОЛЖЕН БЫТЬ КРУПНЫМ И ЧИТАЕМЫМ.
Ширина корпуса телефона — не менее 80% ширины холста (примерно 880 пикселей из 1080).
Телефон стоит фронтально, без наклона и без разворота в перспективе.

Скриншот показывается в КРУПНОМ масштабе: его ширина равна ширине экрана телефона.
Видна ВЕРХНЯЯ ЧАСТЬ скриншота, нижняя часть уходит за нижний край холста вместе с корпусом —
это правильно и так задумано. НЕ УМЕНЬШАЙ скриншот ради того, чтобы уместить его целиком:
лучше показать половину экрана крупно, чем весь экран мелко. Текст интерфейса на готовом
кадре должен читаться так же легко, как на телефоне в руке.

Верхняя грань корпуса с вырезом камеры видна полностью. Боковые грани видны.
Нижняя грань за кадром.

ПРАВИЛО 3 — ТЕКСТ.
Занимает только верхние 20–24% холста, выключка по центру, отступ сверху ~90 пикселей.
• Заголовок: высота прописной буквы 110–130 пикселей, максимум 2 строки.
  Жирный скруглённый гротеск вроде Nunito ExtraBold.
• Подзаголовок: высота прописной 52–60 пикселей — не меньше половины заголовка.
  Одна строка, то же семейство, начертание SemiBold. Если фраза не влезает в строку —
  сократи её, но не уменьшай кегль.
Текст не заходит на телефон и не перекрывается им.

ПРАВИЛО 4 — ФОН.
Мягкий однотонный градиент в заданной для кадра гамме. Растительные мотивы — только
как ЕДВА РАЗЛИЧИМАЯ подложка: крупные размытые силуэты листьев по краям, контраст низкий,
насыщенность приглушённая. Фон не должен спорить с телефоном за внимание и не должен
выглядеть как обои с узором. Никаких ярких плодов, ягод и цветов на переднем плане.

СТИЛЬ: тёплый, спокойный, для аудитории 35+. Без неона, без глянцевого 3D, без людей,
без иконок магазинов, без рамок вокруг холста. Текст только на русском, без ошибок
и без переносов слов по слогам.
```

## Проверка готового кадра

Уменьшите кадр до ширины 300 пикселей — примерно так его видно в галерее магазина.
Если заголовок читается, а на экране телефона различимы названия культур и кнопки —
кадр годится. Если интерфейс превратился в серую кашу — телефон слишком мелкий,
верните генерацию с указанием: «сделай телефон крупнее, экран должен занимать
не менее 75% высоты кадра, нижнюю часть корпуса обрежь краем холста».
