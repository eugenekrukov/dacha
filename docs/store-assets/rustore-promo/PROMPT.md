# Промпты для ChatGPT Image 2.0

## Общие правила (действуют для всех кадров)

```
Ты создаёшь промо-изображение для карточки мобильного приложения в магазине приложений RuStore.
Размер: 1080 × 1920 пикселей, вертикальный.

ГЛАВНОЕ ПРАВИЛО: приложенный скриншот вставляется внутрь мокапа телефона БЕЗ ЕДИНОГО ИЗМЕНЕНИЯ.
Не перерисовывай интерфейс, не меняй ни одной буквы, цифры, иконки или цвета внутри экрана.
Не переводи текст. Не «улучшай» вёрстку. Скриншот — точный контент, а не референс для рисования.
Если не можешь вставить изображение как есть — сообщи об этом, а не перерисовывай.

Композиция кадра сверху вниз:
1. Верхняя треть — текстовый блок на чистом фоне.
   • Заголовок: очень крупный, жирный, скруглённый гротеск (как Nunito ExtraBold), 2–3 строки,
     выключка по центру. Часть слов выделена акцентным цветом, остальные — тёмным.
   • Подзаголовок: одна строка, тот же шрифт средней насыщенности, примерно втрое мельче
     заголовка, приглушённый тёмный цвет.
2. Нижние две трети — реалистичный мокап современного смартфона без логотипов:
   тонкая тёмная рамка, скруглённые углы, вырез камеры сверху.
   Телефон повёрнут в лёгкой изометрии — наклон 6–10 градусов, слегка развёрнут в объёме,
   нижняя часть корпуса уходит за нижний край кадра. Под телефоном мягкая рассеянная тень.
   Экран занимает основную площадь кадра и остаётся полностью читаемым.
3. Фон — мягкий градиент в заданной для кадра гамме, поверх него крупные полупрозрачные
   силуэты садовых листьев и растений по углам и краям (акварельно-иллюстративные, низкий
   контраст, 10–20% площади). Фон не перекрывает ни текст, ни экран телефона.

Стиль: тёплый, дружелюбный, «садовый», для аудитории 35+. Чисто, много воздуха.
Без неона, без 3D-глянца, без стоковых людей, без рамок и подписей магазина.
Весь текст на русском языке, без орфографических ошибок и без переносов слов.
```

«Напоминания / и советы». Иконки внутри кружков оранжевые, простые линейные:
блокнот с галочкой, росток, колокольчик.
