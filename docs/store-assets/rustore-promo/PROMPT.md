# Промпты для ChatGPT Image 2.0

## База — подставляется в начало каждого кадра

```
Создай промо-изображение для карточки мобильного приложения в магазине RuStore.
Размер холста: ровно 1080 × 1920 пикселей, вертикальный.

ПРАВИЛО 1 — СКРИНШОТ НЕПРИКОСНОВЕНЕН.
Приложенный скриншот вставляется в экран телефона без единого изменения. Не перерисовывай
интерфейс, не меняй ни одной буквы, цифры, иконки, отступа или цвета внутри экрана.
Не переводи текст, не «улучшай» вёрстку, не дорисовывай элементы. Это точный контент,
а не референс для рисования. Если вставить изображение как есть невозможно — напиши об этом
текстом, но не перерисовывай интерфейс по-своему.

ПРАВИЛО 2 — ТЕЛЕФОН ЦЕЛИКОМ В КАДРЕ.
Мокап телефона помещается в холст полностью: видны все четыре грани корпуса, включая нижнюю.
Ничего не выходит за края холста и не обрезается краем кадра. Между корпусом телефона
и любым краем холста — отступ не меньше 60 пикселей.
Скриншот внутри экрана показан целиком, сверху донизу, без обрезки и без масштабирования
по одной оси. Пропорции скриншота сохраняются.

ПРАВИЛО 3 — РАЗМЕРЫ ТЕКСТА (обязательные пропорции).
• Заголовок: высота прописной буквы примерно 110–130 пикселей, 2–3 строки, выключка по центру.
  Шрифт — жирный скруглённый гротеск вроде Nunito ExtraBold.
• Подзаголовок: высота прописной буквы примерно 52–60 пикселей — то есть НЕ МЕНЬШЕ ПОЛОВИНЫ
  высоты заголовка. Одна-две строки, тот же шрифт, начертание SemiBold.
  Подзаголовок обязан читаться на превью величиной с ноготь — если он выглядит мелкой
  подписью, увеличь его.
• Между заголовком и подзаголовком — воздух примерно в половину высоты строки заголовка.

КОМПОЗИЦИЯ сверху вниз:
1. Отступ сверху ~120 пикселей.
2. Заголовок, под ним подзаголовок. Весь текстовый блок занимает верхние 28–34% холста.
3. Ниже — мокап современного смартфона без логотипов: тонкая тёмная рамка, скруглённые углы,
   вырез фронтальной камеры. Корпус слегка развёрнут в объёме и наклонён на 5–8 градусов,
   под ним мягкая рассеянная тень. Телефон занимает оставшиеся 60–66% холста по высоте
   и помещается целиком (см. правило 2).
4. Фон — мягкий градиент в заданной для кадра гамме; поверх него крупные полупрозрачные
   силуэты садовых листьев по углам, акварельно-иллюстративные, низкоконтрастные.
   Фон не заходит на текст и не перекрывает экран телефона.

СТИЛЬ: тёплый, «садовый», спокойный, для аудитории 35+. Много воздуха, ничего лишнего.
Без неона, без глянцевого 3D, без людей, без иконок магазинов, без рамок вокруг холста.
Текст только на русском, без ошибок и без переносов слов по слогам.
```

## Склеенная пара (кадры 01 и 03)

Генерировать ОДНИМ изображением 2160 × 1920, затем разрезать ровно пополам и загрузить
как два соседних скриншота — в галерее они образуют одну панораму.

```
Создай промо-изображение 2160 × 1920 пикселей — это ДВА вертикальных кадра рядом,
которые будут разрезаны ровно пополам по центру и показаны как два соседних скриншота
в галерее магазина приложений.

Действуют все правила базового промпта (скриншот неприкосновенен, размеры текста,
телефон целиком в своей половине).

Фон — единый мягкий градиент от тёплого кремового к персиковому, непрерывно перетекающий
через середину холста, с полупрозрачными силуэтами садовых листьев. Линия разреза
не должна быть заметна: никаких швов, рамок и смены цвета по центру.

Левая половина: заголовок «Все задачи дачи на одном экране», подзаголовок «Приложение само
подскажет, что делать сегодня.», ниже мокап телефона с первым приложенным скриншотом.
Правая половина: заголовок «Весь сад под учётом», подзаголовок «Каждая культура — от посева
до урожая.», ниже мокап телефона со вторым приложенным скриншотом.

Оба телефона стоят целиком в своих половинах и не пересекают центральную линию.
Каждая половина должна читаться и отдельно: текст и экраны не попадают на линию разреза.
Единственное, что связывает половины, — общий фон и общий ритм композиции.
```
