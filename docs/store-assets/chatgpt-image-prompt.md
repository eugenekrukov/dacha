# Промпт для ChatGPT Image 2.0 — промо-скриншоты RuStore

> Исходники — `docs/store-assets/screenshots-raw/`. План кадров — `screenshots-plan.md`.

## ⚠️ Важное ограничение (прочитать до генерации)

Генеративные модели **перерисовывают** содержимое экрана внутри мокапа: кириллица плывёт,
цифры и подписи меняются, иконки искажаются. Для витрины магазина это критично — там показан
не ваш продукт, а его галлюцинация, и это ещё и повод для отклонения модерацией.

Поэтому промпт ниже написан так, чтобы модель делала **только подложку и текстовый слой**,
а реальный скриншот вставлялся в мокап **без перерисовки**. Проверять каждый результат: если
внутри экрана телефона текст отличается от исходника хоть одним символом — кадр брак.

Если модель всё равно перерисовывает UI (типичное поведение), надёжный путь — сгенерировать
этим промптом **только фон** (без телефона), а мокап со скриншотом и текст наложить в любом
редакторе. Так и задумано в варианте Б.

## Вариант А — кадр целиком (пробовать первым, проверять придирчиво)

```
Создай промо-изображение для карточки мобильного приложения в магазине приложений.
Формат: вертикальный, 1080×1920 пикселей.

ВАЖНОЕ ПРАВИЛО: приложенный скриншот вставь внутрь мокапа телефона БЕЗ ИЗМЕНЕНИЙ —
не перерисовывай, не переводи, не меняй ни один символ текста, ни одну цифру, ни одну
иконку внутри экрана. Скриншот — это точное содержимое, а не референс для перерисовки.

Композиция:
— Верхние 30% кадра: текстовый блок на чистом фоне.
  Заголовок: «{ЗАГОЛОВОК}» — крупный, жирный, шрифт Nunito ExtraBold, цвет #1F2937,
  слово «{АКЦЕНТ}» выдели цветом #FF7B00.
  Подзаголовок под ним: «{ПОДЗАГОЛОВОК}» — Nunito SemiBold, размер примерно вдвое меньше
  заголовка, цвет #1F2937 с прозрачностью 70%, одна-две строки.
— Нижние 70%: мокап современного Android-смартфона без брендинга, тонкая тёмная рамка,
  скруглённые углы, лёгкий наклон 4 градуса влево, мягкая тень под ним. Внутри экрана —
  приложенный скриншот, полностью, без обрезки важных элементов.
— Фон: мягкий вертикальный градиент от тёплого кремового #FFF8EB сверху к светло-персиковому
  #FFE8CC снизу. Допустимы очень деликатные природные детали по краям — размытые силуэты
  листьев или лёгкая текстура — но они не должны отвлекать от телефона и не должны
  перекрывать текст.

Стиль: чистый, светлый, дружелюбный, для аудитории 35+. Никакого неона, никаких 3D-эффектов,
никаких стоковых людей. Текст только на русском языке, без орфографических ошибок.
```

Подставлять `{ЗАГОЛОВОК}` / `{АКЦЕНТ}` / `{ПОДЗАГОЛОВОК}` из таблицы `screenshots-plan.md`.

Для **тёмных кадров** (6 и 10) заменить в промпте цвета: фон — градиент от `#1A1512` к
`#241C16`, заголовок — `#FFF8EB`, акцент — `#FFC13B`, подзаголовок — `#FFF8EB` с прозрачностью 70%.

## Вариант Б — только фон-подложка (надёжный)

Если вариант А искажает UI. Генерируем пустую подложку, телефон со скриншотом и текст
накладываем сами.

```
Создай пустую фоновую подложку для промо-изображения мобильного приложения.
Формат: вертикальный, 1080×1920 пикселей.
Мягкий вертикальный градиент от тёплого кремового #FFF8EB сверху к светло-персиковому
#FFE8CC снизу. По нижним углам — очень деликатные, сильно размытые силуэты садовых листьев
в тёплых зелёных тонах, не более 15% площади кадра, низкая контрастность.
Центральная и верхняя части кадра должны остаться чистыми и однородными — туда будут
наложены текст и мокап телефона.
Без текста. Без предметов. Без людей. Без рамок.
```

Один такой фон (и один тёмный) переиспользуется для всех 10 кадров — это ещё и даёт
визуальное единство серии, которого от 10 отдельных генераций добиться сложно.

## Панорамная пара (кадры 1–2)

Генерировать **одним изображением 2160×1920**, затем разрезать пополам:

```
… (тот же промпт, что вариант А, но:)
Формат: горизонтальный, 2160×1920 пикселей — это ДВА промо-кадра рядом, которые будут
разрезаны пополам по центру и показаны как два соседних скриншота в галерее магазина.
Фон-градиент должен непрерывно перетекать через середину.
В левой половине: текстовый блок «{ЗАГОЛОВОК-1}» сверху и мокап телефона со скриншотом 1,
смещённый вправо и уходящий за линию разреза примерно на 15% своей ширины.
В правой половине: текстовый блок «{ЗАГОЛОВОК-2}» сверху и мокап телефона со скриншотом 2.
Обе половины должны читаться и по отдельности: ключевой текст и экран каждого телефона
не должны попадать на линию разреза.
```

## Чек-лист приёмки кадра

- [ ] Текст внутри экрана телефона **посимвольно совпадает** с исходным скриншотом.
- [ ] Заголовок читается на превью-размере (галерея показывает кадр примерно в 4 раза меньше).
- [ ] Ни одно слово заголовка не перекрыто мокапом.
- [ ] Цвета соответствуют фирменным (`#FF7B00`, `#FFF8EB`), а не «похожим» оттенкам.
- [ ] Нет артефактов на границе телефона и фона.
- [ ] Кириллица без искажений и лишних диакритик.
