# База данных

PostgreSQL, БД `dacha_db`, пользователь `dacha_user`. Миграции: `backend/src/db/migrations/`, нумерация 001–059.

> ⚠️ **Причина «`must be owner of table X`» — владелец таблицы.** Если DDL когда-то выполнялся
> суперюзером (`sudo -u postgres psql`), таблица принадлежит `postgres`, и `npm run migrate`
> от `dacha_user` на ней падает. Лечится `ALTER TABLE <t> OWNER TO dacha_user`. Так чинили
> 2026-07-02 (`care_alert_log`, `garden_beds`, `subscription_emails`) — после этого полная цепочка
> проходит. При появлении такой ошибки на новой таблице — тот же рецепт, см. `backend/CONVENTIONS.md` §4.
> Отдельная грабля: таблица, созданная суперюзером, требует ещё и явного GRANT для `dacha_user`
> (миграция 055 докатывала его для `garden_beds`).

## Ключевые таблицы/поля
- `crops.climate_zones` — JSONB, USDA зоны 3–6
- `crops.watering_details` — JSONB `{frequency_days, notes}`
- `crops.fertilizing_schedule` — JSONB массив этапов
- `crops.diseases`, `crops.pests` — JSONB
- `crops.good_neighbors`/`bad_neighbors` — TEXT[]
- `gardens.climate_zone` — fallback через `getZoneForRegion(region)`
- `guide_entries` + `crop_guide_entries` — справочник проблем растений (78 записей на 2026-07-02)
- `payments`, `users.payment_method_id/auto_renew/plan` — ЮKassa
- `vk_post_queue` — очередь автопостинга. Миграции 058/059 добавили `telegram_*` (статус
  публикации в Telegram независим от ВК) и `telegram_body`
- `garden_beds` (052) + `plantings.bed_id` — грядки; `crops.family` (053) — семейство для севооборота
- `crops.slug` (056) — для статических страниц `/spravochnik/`
- `today_task_dismissals` (054) — создана, но роуты и клиенты не реализованы (фича не доделана)
- `install_events` (057) — аналитика первых запусков

## Enum-подобные значения (без CHECK, синхронить вручную с кодом)
```
action_type:    watering | fertilizing | treatment | transplanted | other
                + thinning | runner_removal | bolt_removal | deflowering | staking
planting.stage: sowing | growing | flowering | harvesting | transplanted | done
conditions:     soil | greenhouse
store:          rustore | gplay | samsung | web   (samsung-флейвор снят с публикации,
                значение в БД у старых аккаунтов остаётся)
```
