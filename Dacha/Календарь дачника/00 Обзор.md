# Календарь дачника — обзор проекта

> ⚠️ Источник истины — репозиторий `C:\Projects\Dacha\Календарь дачника`. Эта база — навигация + факты, которых нет в репо. При конфликте верь репо.

> **Две даты в шапке каждой заметки:**
> `обновлено` — когда последний раз меняли текст. `проверено` — когда последний раз сверяли
> содержимое с репозиторием, даже если менять ничего не пришлось. Расходящиеся даты — норма;
> опасна старая дата **проверки**: значит, заметку давно никто не сверял с кодом, и она может
> уверенно утверждать то, что перестало быть правдой (так было с [[06 Монетизация]] —
> три недели описывала отменённую модель). Сверять раз в месяц или после крупных изменений.

## Что это
Мобильное + веб-приложение для дачников: календарь работ, журнал посадок/действий, погода,
рекомендации, лунный календарь, грядки и севооборот, дневник урожая, справочник культур и проблем
растений. MVP завершён, в проде, идёт пост-MVP-разработка. Монетизация — free+premium
(см. [[06 Монетизация]]).

## Стек
- **Backend**: Node.js 20 + Fastify 4 + PostgreSQL
- **Web**: React + Vite + TypeScript + Tailwind
- **Android**: Kotlin + Jetpack Compose + Hilt, флейворы `rustore`/`gplay` (samsung удалён 2026-06-30)

## Прод
- Backend: https://dacha.studio1008.com/ (pm2 `dacha-api`)
- Web: https://dacha.studio1008.com/app/
- Android package: `ru.dachakalend.app`
